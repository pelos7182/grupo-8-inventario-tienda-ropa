\# Sistema de Gestión de Inventario - Grupo 8



\## Descripción

Proyecto formativo para desarrollar un sistema de gestión de inventario para una tienda de ropa.



\## Funcionalidades previstas

\- Registro y consulta de prendas.

\- Organización por categorías, tallas y colores.

\- Control de existencias.

\- Registro de entradas y salidas de productos.

\- Gestión de proveedores.

\- Alertas de bajo inventario.

\- Generación de reportes.



\## Herramienta de versionamiento

Git se utilizará para el control de versiones local y GitHub para almacenar el repositorio remoto.
